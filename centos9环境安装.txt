【安装步骤】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 上传文件到服务器 /home 目录：
   • ydinstall.sh
   • ydindd.sh
   • mysql-packages.tar.gz

2. 执行安装命令：
   cd /home && chmod +x ydinstall.sh && ./ydinstall.sh

3. 按提示输入 MySQL root 密码（至少4位）

4. 等待安装完成（约5-10分钟）


【卸载步骤】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

⚠️  如果安装过程失败，运行下面的卸载命令：

cd /home && chmod +x ydindd.sh && ./ydindd.sh

【重要提示】SSH 登录问题解决方案
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

如果安装后 SSH 无法登录（极少数情况）：

原因：OpenSSL 版本与 SSH 服务版本不匹配

解决方法（通过 VNC 控制台登录）：

1. 检查版本冲突：
   openssl version
   ssh -V

2. 方案一：降级 OpenSSL（推荐）
   yum downgrade openssl
   yum downgrade openssl
   yum downgrade openssl
   systemctl restart sshd

3. 方案二：升级 SSH 服务
   yum install openssh-server -y
   systemctl restart sshd

4. 验证服务状态：
   systemctl status sshd

注意：最新版脚本已优化，会自动检查 OpenSSL 避免此问题。
